## 🚀 Highlights of Release v3.100

Release v3.100 expands the PocketGull superfamily into **academic mathematics**, **observational astronomy**, and **high-throughput scientific telemetry**, while reaffirming the project\'s core mission: **humanist healthcare legibility and life-critical information integrity**.

### 1. 📐 PocketGull Math: Peer-Reviewed Scientific Typesetting
- **68 UPM Robust Stem Weight**: Permanently cures dark-mode hairline collapse in LaTeX and Typst formulas, ensuring exponents and fraction lines remain crisp and readable on obsidian clinical monitors.
- **ISMP Life-Critical Disambiguation**: Enforces slashed zero (0̸ / zero), curved foot l (cv05), and serifed capital I (ss02) across mathematical notation, preventing lethal collisions in drug dosages and biomarker indices.
- **Stepped Delimiters**: Seamlessly scaled brackets and parentheses (.v1 1000 UPM to .v4 2200 UPM).
- **Procedural Planetary & Reaction Operators**: Ingested Sun ☉, Earth ⊕, Jupiter ♃, Saturn ♄, equilibrium harpoons ⇌, and reversible reaction arrows ↔.

### 2. 🔭 Observational Astronomy & Scotopic 650nm Red Mode
- **Zero-Rhodopsin Photobleaching**: Deep red HUD palette (#ff3333 on #000000) designed for dark-sky observatories (Mauna Kea, Paranal, La Palma) to protect night-adapted vision.
- **80-Column FITS Header Compliance**: Zero horizontal column shear across 4096×4096 astronomical CCD metadata cards.

### 3. 🖥️ Live Terminal Telemetry CLI (pocketgull-cli)
- Zero-shear, live-streaming terminal dashboard powered by PocketGull Mono (scripts/pocketgull_telemetry_cli.py):
  - --mode clinical: Neuro-ICU intensive care telemetry with real-time sub-cell ECG waveforms (_/\_) and plethysmograph traces.
  - --mode astro: Observational telescope console with live equatorial coordinates (RA/Dec/Airmass) and Julian Date tracking.
  - --mode system: Kernel engine metrics, CPU/RAM usage, and foundry invariant telemetry.

### 4. 📦 Multi-Format Distribution Packages
- **Python / PyPI**: pocketgull_math-3.1.0-py3-none-any.whl (import pocketgull_math as pgm; pgm.use(\'dark\')).
- **LaTeX / CTAN**: pocketgull-math.sty and upload archive pocketgull-math.zip.
- **Typst Package Repository**: @preview/pocketgull-math:3.1.0 with verified 800×600 PNG preview.
- **Matplotlib**: 4 production stylesheets (pocketgull-dark, pocketgull-light, pocketgull-astro-night, pocketgull-bio).
- **Global Package Registries**:
  - Homebrew Cask: rew install --cask font-pocketgull
  - Windows Package Manager: winget install PocketGull.Font
  - Fontsource (NPM): 
pm install @fontsource/pocketgull
